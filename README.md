Sistema de gestión de usuarios:
Sistema web desarrollado con HTML, CSS, MySQL, PHP y JS

## Funcionalidades:

1.Gestión de usuarios.
2.Sistema CRUD que incluye alta, baja y modificación de usuarios.
3.Gestión de horarios.
4.Control de asistencia.
5.Sistema de Login separado por roles de usuarios(Administrador, Supervisor, Funcionario).

## Como ejecutar el proyecto:

6.Clonar el repositorio.
7.Importar la base de datos.
8.Ejecutar el proyecto en XAMPP.
9.En "Capturas" se pueden ver imágenes de distintas partes del proyecto.
