Sistema de gestión de usuarios:
Sistema web desarrollado con HTML, CSS, MySQL, PHP y JS

## Funcionalidades:

-Gestión de usuarios.
-Sistema CRUD que incluye alta, baja y modificación de usuarios.
-Gestión de horarios.
-Control de asistencia.
-Sistema de Login separado por roles de usuarios(Administrador, Supervisor, Funcionario).

## Como ejecutar el proyecto:

-Clonar el repositorio.
-Importar la base de datos.
-Ejecutar el proyecto en XAMPP.
